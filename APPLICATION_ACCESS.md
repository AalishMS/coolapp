## 🔧 **If You Can't Access**

### **Common Solutions:**
1. **Clear browser cache** (Ctrl+Shift+R)
2. **Try incognito/private mode**
3. **Check if another app uses port 3000**
4. **Disable firewall temporarily**
5. **Try a different browser**

### **WSL Specific:**
1. Use network IP: http://172.27.32.151:3000/
2. Set up port forwarding from Windows
3. Check Windows Firewall settings

### **Last Resort:**
1. Kill the process: `pkill vite`
2. Restart with different port: `npm run dev -- --port 3001`
3. Use preview mode: `npm run build && npm run preview`
